## 它能做什么

一句话分出几件事，几个同学各做各的，一起做完。

- **用你现成的 Chrome** — 直接在你已登录的 Chrome 里开自己的窗口干活，网站还是你登录好的那个状态。不用重新登录，也不用交出密码。
- **先在后台做** — 点屏幕、按按键都先在后台做，你照常用电脑。后台做不了的那一步，才会切到前台。
- **边做边聊** — 交出去的事单独做，你接着问别的。做到第几步、做没做完，工作卡上都有。
- **直接交成品** — PPT、Word 直接做好，在聊天里就能翻看，改过的每一版都留着。
- **到点自己做** — 跟它说一句「每天早上 8 点给我发 AI 新闻简报」，就排好了。
- **目标自己拆** — 像「三个月读完 6 本书」这种长期目标，它拆成步骤，一步步跟进。

用国产模型 **DeepSeek V4 Flash** 就能做到。

## 安全与隐私

- **数据留在你的 Mac 上** — 只在本机运行，密钥放进钥匙串；想带走，一键导出。
- **删的文件进废纸篓** — 不是直接抹掉，随时能找回来。
- **碰不到钥匙串和邮件** — 它跑的命令进不了钥匙串、邮件、信息和 Safari 的数据。
- **屏幕变了，再问一次** — 你点了同意，屏幕却变了，它会停下来重新问你。
- **不记**：密码、卡号、证件号。
